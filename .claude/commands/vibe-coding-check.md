# Vibe Coding Check

このコマンドは、コードが「バイブコーディング」（AI 丸投げ・理解なし生成）かどうかを 22 項目で評価します。

## 呼び出し方

以下のいずれかで呼び出してください。

- `/vibe-coding-check`
- `vibe-coding-check`
- `バイブコーディングチェック`
- `バイブコーディングかチェックして`

## チェック対象

ユーザーが貼り付けたコード、または直近の変更差分（`git diff`）を対象にします。
対象が明示されていない場合は `git diff` を使ってください。

---

## 評価項目（22 項目）

### 【高リスク】

1. **コードの意図が不明確**
   - 何をしたいのかコードから読み取れない
   - 変数・関数名が処理内容と乖離している

2. **重複コードの存在**
   - 同じロジックが複数箇所に散在している
   - コピペで増殖した痕跡がある

3. **未使用コード**
   - import、変数、関数が使われていない
   - コメントアウトされた死コードが残っている

4. **エラーハンドリングの過不足**
   - 例外を握りつぶしている（catch して何もしない）
   - または過剰に try-catch を積み重ねている

5. **命名の不一貫**
   - 同じ概念に複数の名前が使われている
   - Kotlin の命名規則（camelCase / PascalCase）に違反している

6. **不要な抽象化**
   - 1 回しか使わないのに interface や抽象クラスを作っている
   - 「将来のため」という名目で過剰に汎用化されている

7. **テストの欠如**
   - ViewModel / UseCase / Repository にテストがない
   - テストしやすい設計になっていない

8. **ライブラリバージョン混在**
   - 同じライブラリの複数バージョンが混在している
   - BOM を使わず個別バージョンが散在している

9. **ハルシネーション**
   - 存在しない API・クラス・メソッドが使われている
   - Kotlin / Android の仕様と食い違っている

---

### 【中リスク】

10. **過剰なコメント**
    - コードを見ればわかることをコメントで説明している
    - 古くなったコメントが残っている

11. **ファイル構成の問題**
    - 1 ファイルに複数の責務が混在している
    - MVVM の層（UI / ViewModel / Repository / DAO）が正しく分離されていない

12. **ログ出力の不統一**
    - `println` と `Log.d` が混在している
    - 本番コードに `println` が残っている

13. **設定の散在**
    - ハードコードされた定数が各所に点在している
    - 設定値が一元管理されていない

14. **依存関係の不自然さ**
    - UI 層が Repository を直接参照している
    - Hilt の注入ポイントが不自然

15. **データ型の不整合**
    - Flow / LiveData / StateFlow が混在している
    - nullable と non-null の扱いが場所によって異なる

16. **非同期処理の問題**
    - `runBlocking` を UI スレッドで呼んでいる
    - `viewModelScope` の外で coroutine を起動している

17. **セキュリティ対策不足**
    - 機密情報をログ出力している
    - SharedPreferences に暗号化なしで保存している

18. **パフォーマンス問題**
    - `LazyColumn` の中で重い処理を毎回実行している
    - Room クエリを不必要に繰り返し呼んでいる

---

### 【低リスク】

19. **README の薄さ**
    - セットアップ手順や概要が書かれていない

20. **Git コミットの乱雑さ**
    - コミットメッセージが「fix」「update」のみ
    - 無関係な変更が 1 コミットに混入している

21. **ライセンス表記**
    - LICENSE ファイルがない、または不適切

22. **ディレクトリ構成**
    - CLAUDE.md / AGENTS.md に記載の構成と乖離している

---

## 評価基準

各項目を以下で評価してください。

| 記号 | 意味 |
|------|------|
| ✅ | 問題なし |
| ⚠️ | 要確認（軽微または判断が難しい） |
| ❌ | 問題あり（修正推奨） |

## 注意事項

- レビューのみ依頼された場合はコード変更を行わないでください。
- 修正も依頼された場合は、修正後に `.claude/prompts/test.md` に従ってビルドを確認してください。
